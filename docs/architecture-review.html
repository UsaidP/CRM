CANDIDATE #1 • GIT HOT SPOT #1

Brochure Ingestion Domain Module Deepening

Strength: High (Core Hotspot)
Problem Diagnosis

upload-brochure/route.ts is 369 lines importing 7 separate services. It orchestrates multipart body parsing, base64 payload decoding, remote fetching, MahaRERA download, text parsing, extraction, persistence, deduplication, and media upload directly in an HTTP route. This breaks ADR-0001 (routes must be thin adapters) and makes testing impossible without mocking full Next.js Request/Response mechanics.

Files: src/app/api/v1/inventory/upload-brochure/route.ts
Proposed Architecture
// Target Domain Module Contract
export async function ingestBrochure(
source: BrochureSource,
context: IngestionContext
): Promise<BrochureExtractionResult>

Route simplifies to an 18-line transport adapter that parses the HTTP request, calls ingestBrochure, and returns standard JSON.

CANDIDATE #3 • SECURITY & COMPLIANCE

Permission Seam Enforcement (ADR-0001 Extension)

Priority: Top Immediate (P0)
Vulnerability Analysis

In src/app/api/v1/leads/[id]/route.ts, requirePermission is imported on line 2 but never invoked. Handlers call requireSession(req) directly. An authenticated agent with scoped permissions can bypass row-level scoping and retrieve or alter any lead in the organization by ID.

Also affecting: leads/[id]/requirements, leads/[id]/communications, leads/bulk-update
Remediation Architecture
// In leads/[id]/route.ts
const auth = await requirePermissionWithScope(req, 'leads:view_all');
if (!auth.ok) return auth.response;
const where = await scopedLeadFilter(session, scope);
const lead = await prisma.lead.findFirst({ where: { id, ...where } });

Restores complete compliance with ADR-0001 Decision 4: "requirePermission is the only permission seam in routes."

CANDIDATE #5 • DEFENSIVE CODING

Unified API Handler Seam (Error Masking)

Security & Hygiene
Problem Diagnosis

Over 45 route handlers catch raw errors and echo { success: false, error: error.message } directly to HTTP clients. This leaks Prisma query exceptions, database schema table names, and system details to consumers.

Solution: withApiHandler Wrapper

Wrap route exports in withApiHandler(async (req, ctx) => { ... }) which logs detailed telemetry internally while sanitizing public error responses.
